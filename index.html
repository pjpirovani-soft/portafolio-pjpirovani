Sobre mi

Soy un desarrollador web autodidacta especializado en la creación de aplicaciones web prácticas y sistemas de gestión para pequeñas empresas. Cuento con experiencia práctica en proyectos reales, incluyendo una aplicación de gestión empresarial para una panadería sin gluten y una plataforma web con autenticación de usuarios, acceso basado en roles, integración de bases de datos y funciones administrativas.

Mis intereses abarcan el desarrollo web, las aplicaciones basadas en bases de datos, la integración de API, la corrección de errores y la mejora de sitios web y sistemas existentes.

Valoro la comunicación clara, el trabajo organizado y las soluciones prácticas que satisfacen las necesidades reales de las empresas.
