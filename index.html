Sobre mi

Soy un desarrollador web autodidacta especializado en la creación de aplicaciones web prácticas y sistemas de gestión para pequeñas empresas. Valoro la comunicación clara, el trabajo organizado y las soluciones prácticas que satisfacen las necesidades reales de las empresas.

ENC Logística

Next.js 16 · Supabase · TypeScript · Playwright

El problema

Una empresa de logística de última milla necesitaba gestionar envíos multi-origen (18 departamentos, 92 ciudades), entregas con C.I., cobro contra entrega y reportes para clientes B2B, todo desde el celular.

La solución

Plataforma completa con dashboard operativo, portal de clientes B2B, PWA instalable, reportes CSV y seguridad auditada (Rate Limiting atómico + RLS + Ley 6534/2020).

El resultado

App en producción con 5 tests E2E pasando, auditoría de seguridad cerrada con reservas y documentación completa (manuales, PDF comercial y acta de auditoría).

FFAA-MONITOR
